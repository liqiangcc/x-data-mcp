# Issue #240 — .day 第 8 字段 (r7) 语义取证

**诊断分析,非裁决。** 输出 `diagnostic_only: true`;不晋升公共契约字段。

## 结论(对 gen-3 pin 字节机械可重放)

`.day` 每条 32B 记录的第 8 字段(LE u32,此前按 reserved 丢弃)**不是填充**:

| 成员类型 | r7 语义 |
|---|---|
| A 股股票(sh60xxxx/sz000xxx/sz002xxx/sz30xxxx/sh688xxx) | **官方除权除息基准价**(除权日)或**昨收 fen**(普通交易日) |
| B 股(sz200xxx) | 同型——样本 sz.200770 的不匹配日亦被公式复现(仅 ±1 分边界);sz.200725 有部分无事件不匹配 |
| LOF 基金(sz16xxxx)、板块指数(sh880xxx) | **不同语义**——值域达 10⁶-10⁷ 量级且逐日变化,与 gbbq 事件无对应 |

### 股票语义的三层证据

1. **普通日恒等**:样本 24 只股票的 21,666 个可比行中,非事件日 `r7 == prev_close(fen)`。
2. **事件日对账**:r7≠昨收且 r7∉{0, 0x10000} 的日期显著聚簇于同证券
   gbbq cat1(分红送转)/cat2 事件日(sh.600000 为 10/11)。
3. **公式精确复现**:对落在 cat1 事件日的不匹配日,以
   `basis = round((prev_close - f0/10) / (1 + f2/10 + f3/10), 2dp)`
   (f0=每10股红利元, f2=送股, f3=转增) 计算——**61 例逐分精确命中**。
   例:sh.600000 @2008-04-24 prev=35.29, 事件[1.6,0,3,0] →
   (35.29−0.16)/1.3 = 27.02 = r7;@2009-06-09 → (30.59−0.23)/1.4 = 21.69 = r7。

### 如实边界(不夸大)

- **±1 分舍入差 3 例**(如 sh.600519 @2010-07-05 官方 126.50 vs 计算
  126.49):理论值恰落在 .5 分边界,官方按四舍五入(half-up)取整,
  Python banker's rounding 得相邻值——公式本体成立,末位舍入规则是
  half-up。
- **f1≠0(配股类)3 例不符**(sz.000750/000815):简单公式未含配股
  价格项,完整基准价需并入 cat2/配股参数;语义方向不变,公式待扩。
- **1995–1999 年无事件不匹配**(sz.000800 ~105 天、sz.000750 ~103 天
  等,合计 ~217 天):gbbq 对早期事件覆盖不全,r7 在该时段仍波动——
  不据此否定语义,只记录覆盖缺口。
- **2003-08-28 sh.600000**:r7=10.33 vs 昨收 10.32,无事件——单点
  1 分数据异常,如实存疑。
- **退化边界**:sh.600000 自 2010-09-14 起 r7 恒为 `0x10000`(65536),
  样本内其它股票同型;官方已废弃该字段,现行快照中仅为历史遗存。
- **r7=0 段**:sh.600000 在 2008-12-03~26 有 18 个正常交易日 r7=0,
  官方源即如此,非解析错误。
- **首日**:r7(首条记录)= 发行价 fen(sh.600000 为 1000 = ¥10.00)。

### 对 #54 的价值

r7 是**官方逐日发布的除权基准价**——它把"除权日官方认可的调整后昨收"
钉在 fen 精度上。由 r7 序列可在 1999–2010 区间反推官方复权因子链的
**离散化与舍入规则**(fen、half-up),这是 TQ oracle(显示精度受限)
够不着的一层官方一手证据。注意有效期止于 2010-09,不能单独覆盖
#54 所需的现行 QFQ 语义。
